# 性能与运行时生命周期

适用于大量角色或建筑的周期检查、临时表现、缓存及功能开关。案例来自 Better Action Showcase 0.2.3；原生细节核对版本为 U59-744825-SCRPN，已编译并做离线契约检查，未实测游戏 FPS、内存或大型殖民地耗时。换版本重新核对消费者，按本次风险选用提醒。

## 先找实际成本

区分逐帧渲染、模拟更新、事件、任务有效性复核和加载期补丁。N 个对象每模拟秒各检查一次，基本回调数量随 N 增长；原生调度反复调用 `Chore.IsValid` 时还有额外检查，不能只数自己的 Sim 方法。反射或 LINQ 若只在补丁安装时运行，不当成逐次交互成本。

先检查昂贵调用的真实实现。U59 的 `AmountInstance.GetMax()` 会进入属性修饰求和，同一比例读取可局部复用一次上限；不要为省计算跨多个更新缓存可能改变的需求上限。`GameUtil.GetDecorAtCell()` 读取网格与光照，不是全地图扫描。

`FaceGraph.GetEnumerator()` 在 U59 返回接口类型、包装 List 的值类型枚举器，存在装箱分配。先排除根本不需要情境脸的任务再枚举；不为消除这点分配反射绑定私有列表。代码路径、资源大小和离线微基准分别说明，不能换算成实机 FPS 或总内存。

## 注册时机与检查频率

重要状态变化可走已有事件，事件覆盖不到的状态再用适当周期兜底；不默认每帧查询，也不把一秒作为所有系统的统一频率。紧迫中断仍保留原生抢占或及时复核，不为了节流延迟求生。

U59 的 `KMonoBehaviour.Spawn()` 在 `OnSpawn()` 前按 `autoRegisterSimRender`、`simRenderLoadBalance` 注册模拟。需要关闭自动注册或分散同类对象检查时，在 `OnPrefabInit()` 设置相应字段；放在 `OnSpawn()` 已晚于首次注册。负载均衡只分散同帧工作，不减少总检查次数，也不是异步执行。

功能开关要对应实际工作：动作关闭后不再维护只服务于动作的闲置计时和附近查找；动作与情境脸都关闭、只保留事件式招呼时，可以不注册周期更新。全部功能关闭时避免添加无用控制器。配置若支持运行中切换，还需处理取消任务、注册增减和覆盖清理；仅重启生效的配置不必增加热切换机制。

## 缓存什么、由谁释放

组件和属性实例引用可在初始化时获取；同次同步更新按需复用情境快照，任务切换或回调改变其依据时重新读取。关键播放资格在实际领取时仍看当前值，不能复用数秒前的快照。

资源定义缓存按数据库生命周期管理，数据库变化时重建；角色自有表情由角色持有，招呼等独立清理者保留自己的实例。检查缓存是否有界，以及是否长期持有上一局对象。不要全局缓存角色状态或把同一可清理实例交给多个所有者；具体见[复制人任务与效果](duplicants-chores-and-effects.md)。

确认资源加载阶段已经结束后，缺失资源可停止重复尝试并限制日志次数；新的数据库或明确的资源重载再恢复检查。不能把加载早期的暂不可用永久缓存成失败。清理前撤销就绪状态，之后到来的模拟或事件入口应直接让位；异常防护限定在自己可识别的依赖缺失，不吞掉全局错误。

## 有针对性的验证

涉及这些机制时，可覆盖全部开关组合、初始化缺依赖、清理期间回调、反复进出存档与数据库重建；不要求局部修改都执行全套。检查工作是否真正停止、缓存是否重建、其他所有者的覆盖是否仍存在。

托管初始化和原生程序集契约检查可以验证注册意图、接口及计算路径；实际分桶、帧耗时、分配率和渲染还需游戏场景与 profiler。未测时报告具体优化和证据边界，不宣称零 GC、固定提帧比例或任意规模无开销。
